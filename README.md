# Secure Coding akademija – Tjedan 2: samostalni projekti (PRIVATNO, samo za nastavnika)

Ovaj repozitorij sadrži predloške projekata za 15 varijanti, **skrivene testove** za ocjenjivanje i alate.
Polaznici ga **ne smiju vidjeti** – dobivaju samo ZIP svoje varijante preko Moodlea.

- `SPEC_T2.md` – specifikacija (domene, 13 ranjivih mjesta, skriveni testovi)
- `variants.json` – raspodjela V01–V15 (domena + ranjiva mjesta)
- `tools/generate.py` – generiranje varijanti i studentskih ZIP paketa
- `tools/ocijeni.py` – ocjenjivanje predaje skrivenim testovima
- `templates/`, `hidden-tests/` – predlošci i skriveni testovi (Java i .NET)

(Detaljne upute za nastavnika dopunjuju se po završetku izrade.)
