# Predaje polaznika

Ovdje stavi ZIP-ove predaja (npr. `V07-Ime-Prezime.zip`), napravi commit i push, zatim pokreni workflow
**ocijeni** (Actions → ocijeni → Run workflow) s nazivom datoteke. Izvještaj se pojavi u sažetku pokretanja i kao
artefakt. Lokalno: `python3 tools/ocijeni.py --predaja predaje/V07-Ime-Prezime.zip`.
